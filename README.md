# 買取業者ノート

**Kaitori Company Note — Ver.1.0 試作1**

不動産の買取案件が発生したときに、「この物件なら、どの買取業者へ声をかけるか」を素早く判断するためのシンプルな端末内保存アプリです。案件管理やCRMではなく、業者の買取エリア・買取対象・温度感を少ない入力で記録し、スマートフォンからすぐ探すことに特化しています。

ログイン、外部サーバー、外部API、CDN、外部フレームワークは使用しません。通常はIndexedDBへ保存し、利用できない環境だけブラウザの端末内互換保存へ切り替わります。

## 起動方法

### 1. `file://` で直接起動

`index.html` をダブルクリックするか、ブラウザで直接開きます。

- 業者登録・検索・編集・削除
- JSONバックアップ・復元
- CSV出力

は利用できます。ブラウザの制約によりService Worker、PWAインストール、オフラインキャッシュは利用できません。

### 2. ローカルHTTPサーバー

このフォルダをカレントディレクトリにして、例として次を実行します。

```powershell
python -m http.server 8765
```

ブラウザで `http://127.0.0.1:8765/` を開きます。HTTP起動ではService Workerとオフラインキャッシュを利用できます。

### 3. GitHub Pages

フォルダ内容をGitHub Pagesで公開してください。すべて相対パスなので、リポジトリのサブディレクトリでも動作します。PWAとして継続利用する場合は、HTTPSのGitHub Pagesが適しています。

## 画面構成

下部ナビゲーションは次の3画面だけです。

1. **探す** — エリア・買取対象・温度感・お気に入り・フリーワードで該当業者を検索
2. **業者一覧** — 登録済み業者の確認、簡易絞り込み、並び替え
3. **その他** — 件数、バックアップ、CSV、候補設定、アプリ情報

右下の「＋」ボタンから業者を登録できます。

## 業者登録方法

1. 「探す」または「業者一覧」の右下にある「＋」を押します。
2. 業者名を入力します。
3. 必要に応じて、担当者・電話・メール・エリア・買取対象・温度感・お気に入り・一言メモを入力します。
4. 「保存する」を押します。

必須項目は**業者名だけ**です。エリアや買取対象が未選択でも保存できます。電話番号とメールが明らかに不自然な場合は控えめな確認表示を出しますが、入力内容は消しません。

新規登録・複製時に、業者名の正規化一致、電話番号一致、メール一致が見つかると「同じ業者の可能性があります」と表示します。既存業者の詳細を確認するか、同名別会社としてそのまま登録できます。

## 買取業者の探し方

起動直後は「探す」画面です。

- 買取エリアは複数選択できます。
- 買取対象は複数選択できます。
- 温度感は「すべて／積極的／通常／現在休止」から選びます。
- 「お気に入りのみ」を切り替えられます。
- 業者名、担当者、電話、メール、エリア、買取対象、メモをフリーワード検索できます。

異なる分類はAND条件、同じ分類内の複数選択はOR条件です。たとえば「横浜」＋「土地・戸建」は、横浜に対応し、土地または戸建を買う業者を表示します。

広域タグは実務上の包含関係として扱います。たとえば「横浜」検索では、「横浜」に加えて「神奈川県全域」「関東」「全国」の業者も候補に含まれます。

探す画面の並び順は、お気に入り、温度感（積極的→通常→現在休止）、業者名の順です。

## お気に入り

業者カードまたは詳細画面の星を1回押すだけで切り替えられます。お気に入り業者は探す画面の上位へ表示されます。「お気に入りのみ」で絞り込みもできます。

## 温度感

- **積極的** — いま優先して相談する業者
- **通常** — 通常の相談先
- **現在休止** — 現在は仕入れを休止している業者

初期値は「通常」です。色だけでなく、カードと詳細画面へ必ず文字でも表示します。

## 業者一覧と並び替え

初期表示は `Intl.Collator("ja-JP")` を使用した業者名順です。次へ切り替えられます。

- 業者名順
- お気に入り順
- 温度感順
- 更新が新しい順
- 登録が新しい順

業者名、お気に入り、温度感、エリア、買取対象で簡潔に絞り込めます。

## 業者詳細

業者名、担当者、電話、メール、買取エリア、買取対象、温度感、お気に入り、メモ、登録日・更新日を表示します。

- 電話する（`tel:`）
- メールする（`mailto:`、件名「買取案件のご相談」）
- 編集
- 複製
- 削除

削除前には業者名を含む確認を表示します。削除後は数秒間だけ「元に戻す」を利用できます。

## JSONバックアップ

「その他」→「データのバックアップ」→「JSONバックアップを保存」を押します。全業者と設定を1ファイルへ保存します。

```json
{
  "format": "kaitori-company-note-backup",
  "appName": "買取業者ノート",
  "appVersion": "Ver.1.0 試作1",
  "schemaVersion": 1,
  "exportedAt": "ISO 8601日時",
  "companies": [],
  "settings": {}
}
```

ファイル名は `kaitori-company-note-backup-YYYY-MM-DD.json` です。

## JSON復元

「その他」→「データのバックアップ」→「JSONから復元」でファイルを選びます。

- **現在のデータへ追加** — 既存データを残して追加。同じIDは上書きせずスキップし、候補設定は現在値と統合します。
- **現在のデータを置換** — 確認後、現在の業者と設定をバックアップ内容へ置換します。

JSON形式、format、companies配列、ID、業者名、ファイル内重複ID、各項目の型などを、保存データへ触れる前に全件検証します。不正JSONや復元エラーでは、既存データを変更しません。

## CSV出力

「その他」→「データのバックアップ」→「CSVを出力」を押します。

列は、業者名、担当者名、電話番号、メール、買取エリア、買取対象、温度感、お気に入り、メモ、登録日、更新日です。UTF-8 BOM付き、CRLF改行、全項目ダブルクォート形式で、Excelで日本語が文字化けしにくい形式です。CSV入力には対応していません。

## PWA・iPhoneホーム画面追加

HTTPまたはHTTPSで起動したとき、アプリシェルをService Workerへ保存します。iPhoneではSafariの共有ボタンから「ホーム画面に追加」を選択します。ホーム画面では「買」の専用アイコンで起動できます。

初回キャッシュ完了後は、通信がない状態でもアプリを再起動できます。業者データ自体はネットワークではなく、ブラウザの端末内ストレージから読み込みます。

## `file://` とHTTPの違い

| 機能 | `file://` | HTTP / HTTPS |
|---|---:|---:|
| 登録・検索・編集 | ○ | ○ |
| IndexedDB | 対応ブラウザで○ | ○ |
| JSON・CSV | ○ | ○ |
| Service Worker | × | ○ |
| PWAインストール | × | HTTPS等で○ |
| オフラインキャッシュ | × | 初回キャッシュ後○ |

`file://`、localhost、GitHub Pagesは別の保存元（origin）です。各起動方法のデータは自動共有されないため、移行にはJSONバックアップと復元を使ってください。

## 保存場所とデータ保護

業者情報は端末内のブラウザ保存領域へ保存され、外部送信されません。一方、Safariの「履歴とWebサイトデータを消去」、ブラウザのサイトデータ削除、端末初期化などで消失する可能性があります。

**定期的なJSONバックアップを強く推奨します。** バックアップファイルはiCloud Drive、社内の安全な保管場所などへコピーしてください。

## 初期サンプル

初回だけ、操作確認用のサンプル業者を3社登録します。すべて「サンプル」と表示され、実在する業者情報ではありません。「その他」→「詳細設定」→「サンプルデータをすべて削除」で一括削除できます。再読み込みのたびに追加されることはありません。

## 現在の制限

- ログイン、クラウド同期、複数端末同期はありません。
- 案件履歴、商談履歴、査定額、ファイル添付、通知はありません。
- CSV入力はありません。
- 読み仮名項目を持たないため、漢字の並びは厳密な五十音順ではなく `Intl.Collator("ja-JP")` の照合順です。
- `file://` のIndexedDB永続性はブラウザ仕様に左右されます。
- iPhoneの電話・メールアプリの起動、ホーム画面追加、実Excelでの表示は端末側の設定にも左右されます。
- データ量が非常に多い本格CRM用途は想定していません。

## 技術構成

- HTML / CSS / JavaScript
- IndexedDB（DB version 1）
- PWA / Service Worker
- SVG原本からローカル生成した不透明PNGアイコン
- 外部依存・外部通信なし
